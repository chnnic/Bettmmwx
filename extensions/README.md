# 可选功能扩展

此目录预留给以后添加的跨主题或端专属功能；当前没有已发布的扩展包。

新增扩展使用 `extensions/<feature-id>/`，每个扩展独立提供 README，并明确：

1. 功能目的、适用主控版本与作用端（主控 / TG Bot Mini App）。
2. 是否为纯 CSS、是否依赖主题，以及与哪些主题测试过。
3. 安装位置、加载顺序、参数、冲突和卸载方式。
4. 是否会影响布局、可访问性或业务行为。

纯 CSS 扩展可按需提供 `controller.css` 和/或 `tgbot.css`；不适用的端不创建空占位文件。需要叠加时，说明应追加到主题文件之后，并控制总大小。

新功能默认不启用，不自动修改主控设置。脚本、服务端改动或需要额外权限的功能必须单独说明，不能伪装成普通 CSS 主题。
