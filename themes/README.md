# 主题目录约定

每个主题放入独立的 `themes/<theme-id>/`，目录名使用小写英文和短横线。

- `README.md`：主题风格、各端安装入口、版本、变量、依赖与已知限制。
- `controller.css`：可直接粘贴的主控完整样式。
- `tgbot.css`：可直接粘贴的 TG Bot Mini App 完整样式；尚未支持时明确标注，不放空文件冒充实现。
- `assets/`：该主题专属图片等资源，需要时再创建。

主控使用 `data-slot` 组件钩子；Mini App 使用自己的 CSS 变量和类名，不能复制主控样式后只改文件名。两端均须处理浅色、深色、窄屏、禁用态与键盘焦点。

参数集中在每个 CSS 文件的第一个 `:root`；使用主题前缀避免与其他文件冲突。保留认证/角色控制的隐藏规则，不用 CSS 显示本来不可访问的内容，也不隐藏安全警告。

不改变原生开关的业务状态；选中色与危险、警告、在线状态色分开。主控和 Mini App 文件独立维护版本，实质修改时更新 `vYYYY.MM.DD-NN` 与日期。

图片直链应指向本仓库主题目录或明确公开的资源，不能包含令牌、私有主控地址和个人配置。移动资源时处理旧链接兼容；不要随意删除已发布的图片地址。

提交前运行 `git diff --check`，检查 README 相对链接、外部资源地址和 CSS 语法，并测试小屏、大屏、深浅色。最后更新根 README 的主题索引及版本。
